## Status meanings

- **Shipped:** implementation and identified release evidence exist, within the stated test scope.
- **Partial:** useful work is shipped, but a material part of the request remains.
- **Pending:** work remains; a plan or report does not count as implementation.
- **Dependency:** external account/configuration or production acceptance evidence remains.
- **Deferred/superseded:** a later human instruction explicitly narrowed or replaced the earlier scope.
- **Target:** a desired outcome that must follow measurement; it is not an achieved or guaranteed grade.
