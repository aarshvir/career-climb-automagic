# Independent persona audit: busy employed career switcher
11 October 2026 · Jobvance current release · simulated evaluation, not a customer interview

**Verdict: 51.3/100 for this persona today.** Jobvance can delegate cloud document preparation after substantial setup. It does not currently delegate the wider daily search-and-reply loop that would release a busy employee's time. Its strongest contribution is factual control: reusable, user-cleared evidence and explicit approval. The weakest commercial promise is sustained delegation.

**Persona and method.** I modelled a professional with 12 years of operations experience moving toward business analysis, a current employer, confidential metrics, and 15 minutes per weekday. They need relevant roles, truthful transferable evidence, quiet preparation, and reliable next actions. LIVE observed means my own Chrome public-page inspection; SOURCE verified means inspected implementation or release documentation; INFERENCE means a proposed user reaction or consequence. Confidence is stated for findings. I inspected home, career-switcher selection, check entry, privacy, help, contact and pricing. The browser displayed an existing signed-in header, but I made no account changes and did not inspect private loop records, create records, run jobs, upload a CV, send anything, apply or pay. Authenticated execution, production latency, rendered output quality and actual user satisfaction are **Not verified**. Release test totals are evidence of reported checks, not satisfaction.

**What works today.** SOURCE verified: the release documents deployed control/worker services and a tested path from confirmed claims and a user-supplied vacancy to cloud PDF/DOCX/evidence/letter generation, exact approval, downloads, manual tracking and withdrawal. The same document states paid models/search/mail are disabled, Gmail is disconnected, and daily scheduling is absent. Thus rules-based cloud preparation is the available lane; connected market discovery, mailbox triage and scheduled repetition receive no working-feature credit here. [Release:7][r7], [Release:20][r20], [Release:30][r30], [Release:34][r34]. The live homepage qualifies connections as needing setup and consent, which is honest but less precise than “unavailable today.” [Home](https://jobvance.io/), [ProductPage.tsx:146][p146].

**Realistic journey.** LIVE observed: arriving at home, I initially see student examples. Selecting Career-switchers changes the example to an operations analyst and distinguishes preparing stakeholder reports from leading them. The page acknowledges a full working day and transferable experience. The main action remains the free check; Job Loop appears as an ongoing-search section and a navigation link. This is credible preparation positioning, but the most relevant delegate-work promise is not the initial destination. [Home](https://jobvance.io/), [ProductPage.tsx:66][p66], [ProductPage.tsx:144][p144].

In the first 15-minute session, the plausible starting route is the local free check. LIVE observed: its professional entry identifies career-switcher guidance, six steps, one vacancy, English wording analysis, and local privacy. It asks first for a target role and optional company. SOURCE verified: after evidence review, it supports separate factual/disclosure approval, downloads, optional saving, and another action to add the vacancy to the existing tracker. INFERENCE, medium confidence: someone with a CV and vacancy ready could obtain first value in one session, but that completion time was not measured. Someone without a vacancy must source one elsewhere first. [Check](https://jobvance.io/check?audience=professional), [CvCheck.tsx:241][c241], [CvCheck.tsx:246][c246], [CvCheck.tsx:249][c249].

For ongoing delegation, SOURCE verified: /loop is protected by sign-in; App.tsx merely reexports MvpApp, which defines the real routes. The first loop screen directs a new user to a career record. The user must choose their situation, enter name/targets/locations, select one or two pages, review/redact source text, and save privately. Literal suggestions then need individual contextual classification and confirmation. INFERENCE, high confidence: a 12-year record will usually take multiple short sessions to clear usefully; no timed usability study establishes the burden. The free check does not provide an explicit migration into this record. [MvpApp.tsx:44][m44], [JobLoop.tsx:258][j258], [JobLoop.tsx:268][j268], [JobLoop.tsx:273][j273]; interface destination: [Job Loop](https://jobvance.io/loop).

After setup, the user manually adds actual vacancies and starts a run. SOURCE verified: the cloud run can continue after closing the browser, a real benefit for someone returning to work. They return and refresh, inspect source coverage, review each packet, and approve exact facts and disclosures. Contacts require their own research and confirmation; applying remains an employer-site task. With mailbox access unavailable, they also check email separately, update status themselves, and enter follow-up dates. SOURCE verified: Today shows due dates and saved action-needed messages, but the current release has no daily schedule. INFERENCE, high confidence: repeat use is a batch-preparation habit, not a dependable daily delegate. [JobLoop.tsx:260][j260], [JobLoop.tsx:281][j281], [JobLoop.tsx:82][j82], [JobLoop.tsx:259][j259], [Release:34][r34]; [Job Loop](https://jobvance.io/loop).

**Strengths.** LIVE observed: the public examples preserve attribution rather than inflating support into leadership; privacy distinguishes local work, account saving, model consent and separate Gmail access. SOURCE verified: active/confirmed/shareable claims alone enter fresh outputs; stale approvals and unsafe page/font renders block export; unknown pay and eligibility remain labelled unknown. Tracking distinguishes a saved or prepared document from an actual application. Source coverage records unavailable stages instead of silently treating them as an empty market. These controls suit a mid-career applicant whose credibility matters. [Privacy](https://jobvance.io/privacy), [Engine.ts:198][e198], [Runtime.ts:130][rt130], [JobLoop.tsx:83][j83], [JobLoop.tsx:281][j281].

**Findings and acceptance criteria**

1. **High — Most of the needed delegation is unavailable.** SOURCE verified, high confidence. Model/search/mail capabilities are disabled; the runtime explicitly blocks hosted LinkedIn sources and defines unavailable states for unconfigured employer boards/search. No enabled employer feed was established by the inspected release evidence. This is missing configuration/integration, not evidence of a broken successful search. INFERENCE: the user still owns sourcing, inbox review and most decisions. Accept when the entry page lists enabled lanes plainly and a permitted, live discovery source produces dated roles plus honest coverage; mailbox claims require a verified working integration. [Release:20][r20], [Runtime.ts:130][rt130], [Runtime.ts:136][rt136], [Runtime.ts:143][rt143]; [Home](https://jobvance.io/).

2. **High — Career-record setup exceeds the low-effort framing.** SOURCE verified, high confidence. Each claim editor asks for evidence context, source type, passage, context label, substantiated wording, result status and two separate attestations. Suggestions remain individually unsaved/unconfirmed. New profiles default to student and one page. INFERENCE: repetitive approval work can consume several daily budgets before delegation starts. Accept with a professional onboarding path, staged progress/resumption and a compact contextual review queue that preserves individual disclosure control; validate median first useful packet within a stated, measured setup budget. [JobLoop.tsx:15][j15], [JobLoop.tsx:69][j69], [JobLoop.tsx:273][j273]; [Job Loop](https://jobvance.io/loop).

3. **High — “Discreet” does not enforce employer/contact boundaries.** SOURCE verified, high confidence. The checkbox says “Keep my search discreet”; the engine explicitly says this is a review reminder and does not automatically block contacts or guarantee confidentiality. Excluded terms restrict claims/text, not an employer/domain policy. This is a control gap, not a demonstrated leak. Accept when the selector states its present limits beside the checkbox and users can exclude current-employer organisations/domains/contacts, see the blocked decision, and explicitly override only after review. [JobLoop.tsx:269][j269], [Engine.ts:273][e273], [Engine.ts:180][e180]; [Privacy](https://jobvance.io/privacy).

4. **High — Account-erasure help has no available destination.** LIVE observed + SOURCE verified, high confidence. Privacy tells users to contact support for account erasure; Contact says direct support contact details are unavailable. Cloud controls offer withdrawal/disconnection, but the action list contains no loop-record erasure action. A discreet professional cannot establish how to exit with their career record removed. Accept with a functioning, published data-request route and clear retention/deletion scope for source text, claims, runs and artifacts; test receipt and completion using fictional records. [Privacy](https://jobvance.io/privacy), [Contact](https://jobvance.io/contact), [ProductPage.tsx:160][p160], [Engine.ts:145][e145].

5. **Medium — First value and repeat-use records are fragmented.** SOURCE verified, high confidence; burden INFERENCE, medium confidence. The free check saves its own record and optionally adds a vacancy to the existing Applications tracker. The loop copies owned saved CV text, but does not offer a reviewed free-check/vacancy handoff. No /loop link exists in CvCheck.tsx. Accept when a completed check can create a proposed loop record and vacancy with an explicit save preview, preserving source and consent, and when application history has one understandable home. [CvCheck.tsx:249][c249], [JobLoop.tsx:271][j271], [JobLoop.tsx:286][j286]; [Check](https://jobvance.io/check?audience=professional).

6. **Medium — Rules mode does limited career-switch translation.** SOURCE verified, high confidence. The assessment uses phrase overlap; rules composition receives all ranked eligible claims, groups them under fixed evidence-kind headings, and constructs a cover letter with a vacancy quotation and one/two literal facts. This preserves truth, but does not develop a persuasive transition narrative. Actual rendered quality is Not verified. Accept with source-preserving target-role framing, a visible explanation of why chosen experience transfers, and before/after review with employed switchers; do not count disabled AI as the remedy. [Engine.ts:204][e204], [Engine.ts:236][e236], [Engine.ts:249][e249], [Engine.ts:269][e269]; [Job Loop](https://jobvance.io/loop).

7. **Medium — Page holds require a long correction cycle.** SOURCE verified, high confidence. A packet over the chosen page limit is held; the UI directs the user back to career facts to shorten and rebuild. Exact factual review text is read-only. This safety mechanism can create repeated runs for a long senior record. Accept with pre-run length guidance and a source-preserving selection/shortening preview that estimates pages, explains affected facts and obtains fresh approval. A hold must remain enforceable. [Render.ts:46][render46], [JobLoop.tsx:38][j38], [JobLoop.tsx:281][j281]; [Job Loop](https://jobvance.io/loop).

8. **Medium — Follow-ups depend on remembering to return.** SOURCE verified, high confidence. Due dates are filtered in the page and displayed in Today; runs require a user trigger and daily scheduling is unconfigured. No present proactive reminder claim earns credit. INFERENCE: an employee's interview response can remain in a separate inbox while Jobvance appears quiet. Accept with optional, discreet reminders or calendar export and a clear “last checked / not checked” state; test time zones, stale sources and opt-out. [JobLoop.tsx:248][j248], [JobLoop.tsx:259][j259], [Release:34][r34]; [Job Loop](https://jobvance.io/loop).

9. **Medium — Help cannot recover the cloud workflow.** LIVE observed + SOURCE verified, high confidence. /help repeats the six-step free check; it does not explain claim approval, held packets, resume, missing integrations or the distinction between Workspace and Job Loop. Direct support is unavailable. Accept with task-specific loop help for every blocked state, safe recovery instructions and an escalation destination, then test an unfamiliar user recovering without assistance. [Help](https://jobvance.io/help), [Contact](https://jobvance.io/contact), [ProductPage.tsx:191][p191], [JobLoop.tsx:264][j264].

**Scores using the common weights.** These rate the present persona journey, not implementation effort. Confidence is strongest for public trust/positioning and disabled integrations, moderate for unexecuted authenticated interaction and output quality.

Mobile/accessibility credit comes from associated labels, status/alert roles, focus styling, 44px buttons, responsive grids and reduced-motion handling in source. Phone interaction, keyboard completion and assistive-technology output remain Not verified. [JobLoop.tsx:53][j53], [JobLoop.css:4][css4], [JobLoop.css:97][css97].

**Three highest-value improvements.** First, publish the actual enabled service envelope and enable one permitted discovery lane before promising daily delegation. Second, connect the successful free check directly into a resumable professional claim-review workflow so prior effort becomes the first reusable record. Third, make discretion actionable through employer/contact exclusions and a working erasure/support route. Scheduling and optional reminders then turn preparation into a reliable repeat habit.

**Use/pay hypotheses — INFERENCE, medium confidence.** This persona might use the free check for a high-value vacancy immediately and try rules preparation for a small batch once the record is cleared. They are unlikely to return daily just to check disabled lanes. LIVE observed: pricing offers free beta and a disabled $29 thirty-day/ten-pack planned pass; no current purchase was available. A paid claim would need evidence of net time saved across repeated sessions, useful sourced roles, reliable privacy/support, and fewer duplicate edits. Test that with employed switchers using real consented tasks: setup minutes, weekly active minutes saved, approved useful packets, return rate and discreet-control comprehension. Neither a price hypothesis nor reported tests establishes willingness to pay. [Pricing](https://jobvance.io/pricing), [ProductPage.tsx:190][p190].
