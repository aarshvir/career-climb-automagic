# Reviewed administration dashboard

Claude PR29 adds the requested private `/admin` overview, Today, revenue, growth, users, marketing, operations and support views. The previous operations interface remains at `/admin-original`; `/admin2` remains a clearly labelled historical founder view. Accounts and active server-side administration membership remain required.

Codex reviewed the branch at f1097de6b1f92c571659a999ac22166c516016e5 and integrated it onto main2325fed. Two separately assigned reviewers exercised the SQL and frontend boundaries. Review found and corrected these release blockers:

- Private reads and cached views originally followed only the user ID. Both interfaces now bind the actual SDK session and a synchronous auth-event epoch, including batched A→B→A, same-owner new sessions and sign-out. Normal refresh of a token in the same verified SDK session preserves access. Original actions are captured before authentication awaits; responses must match the original actor/range or exact support request.
- Marketing and guest-support failures could become zero counts or retain stale private data. Unknown sources stay unknown, child permission failures revoke the parent view, and Refresh invalidates details and refreshes every visible source. Recorded effective ad status is distinct from configured status; this interface does not activate ads.
- Missing provider accounting used a plan-list-price estimate. The dashboard now reports known USD subtotals, original charged amounts and unknown-money coverage separately. Access revocation does not prove a full monetary refund. Known partial pass refunds retain their correct net amount; unknown refund amounts suppress USD comparisons, averages and charts. Historical payers remain filterable without known USD or a current plan.
- Current subscription labels now follow lifecycle/generation and paid-period authority. Capacity occupancy intentionally follows the broader server admission rule, including temporary checkout reservations; it is not a count of entitled customers.
- A chart hover could refer beyond a subsequently shortened date range. Bounds are checked before rendering its hover marker. Unknown prototype-property routes cannot select an administration page.

The new SQL is read-only, with fixed search paths, active-member checks inside the dashboard and no anonymous/authenticated execution. It returns bounded account/support metadata and aggregate figures, without CV or support-message bodies. Owner emails remain visible to the existing owner role; operators receive the existing masked form. Paid service-period dates are not cash-receipt dates; refund observations restate the original service period. Cohorts are observed retained activity, limited by deletion and the existing 200-event retention cap. The latest 500 classified customer accounts are listed. Reserved test domains/explicit QA metadata and staff membership are exclusions, not proof that every remaining account is a real customer.

Validation includes the complete application suite, independent UI regressions, actual PGlite execution of the migration, application TypeScript, changed-file lint, source/generated Deno checks, the 37-page build and all 12 hosting groups. Exact final counts and hosted observations are in the release receipt. The existing main CI run40179613855 already failed with 95 lint errors and 50 warnings before this PR; changed-file lint is not a claim that repository-wide CI is green.

The first output packager encountered the previously observed OneDrive symbolic-link guard. A fresh inspection of every output entry using dirent, lstat, readlink and resolved paths found 141 files, five directories, no symbolic links and no path escape. The unchanged packager then passed; guards were retained. An early hosting-check invocation preceded the finished build and had no Worker artifact to inspect; final hosting checks ran against the completed artifact. Three older guest-support test mocks initially lacked the actual SDK session/subscription interface; the mocks were corrected without weakening runtime guards. The first native receipt query had an ambiguous JSON operator; parentheses corrected the read-only query. The first backend deployment rejected its inherited absolute import-map path; explicitly binding the included `deno.json` resolved it before successful deployment.
