# Localized subscription edge integration and independent SQL review

The edge integration binds a deliberate billing-country/currency choice to a server-owned, fifteen-minute quote. The versioned SQL catalogue, current Dodo product, exact active localized rule and non-purchasing checkout preview must agree on the first and recurring tax-inclusive amount. A new provider checkout pins that country and currency, disables customer currency/country changes and carries the immutable quote ID. The original ready or uncertain checkout never triggers a new preview, conversion or duplicate purchase. Its existing twenty-four-hour link policy remains separate from quote expiry.

Existing unquoted USD 29/59/99 checkout and historical records retain their original contract. New localized rules may coexist with the unchanged USD base. Renewal, cancellation and refund verification uses the original owned order's product, currency and amount rather than today's selected market or merchant rule. Payment service periods remain the only paid-time authority. Version-two status and cancellation receipts expose original monetary snapshots; an old client viewing a non-USD subscription must refresh instead of presenting its hardcoded USD price.

The independent CV-pass USD-only validator remains unchanged. Regressions include actual Live and isolated Test handler requests carrying INR refunds, a wrong-currency refund rejection, and the SQL integration's localized refund flow.
