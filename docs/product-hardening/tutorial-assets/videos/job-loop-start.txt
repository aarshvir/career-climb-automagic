Job Loop uses a private saved workspace. Sign in to your own account and open Today. Select Import or paste my CV, or choose Career record. If you want to try one comparison without an account, use the free CV check instead.

Open the import step. Read a local CV, paste your career text or choose an owned saved CV if one is available. Review the extracted wording and remove confidential information. Select Continue with this text. Reading the file does not yet save your record.

Check your name, enter one target role per line and add the places where you would work, or Remote. Optional preferences can wait. Leave unknown pay or experience unknown. Confirm that you want the reviewed text saved privately, then select Save career record.

Review one literal passage at a time. Choose Evidence context yourself, and inspect the complete source and nearby heading. In this fictional MBA example, the team estimated a possible result, so choose Projected or estimated. Do not turn it into measured client work. Confirm accuracy and external-use permission only when true, then save the claim.

With useful facts saved, open Opportunities and add the posting you want to apply for. Use the actual title, company, HTTPS link and full description. Leave a named contact out unless you have checked a real source. Save the opportunity, then return to Today to inspect preparation availability.
